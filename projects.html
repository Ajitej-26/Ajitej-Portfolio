    Project 03

    Parkinson's Disease Prediction

  • Early diagnosis of Parkinson's Disease is difficult because traditional methods rely on subjective motor assessments (UPDRS, DaTscan), which often miss subtle non-motor symptoms like voice changes and gait deviations.
  • Tech Stack: Python, Scikit-learn, SHAP, Praat libraries, wearable sensor data.
  • Outcome: Achieved high accuracy in early PD detection, enabling real-time, interpretable predictions. Designed as a clinical decision-support tool (HIPAA-aligned), improving early intervention and reducing healthcare burden.

    • Python Scikit-learn SHAP Machine Learning Data Analysis
